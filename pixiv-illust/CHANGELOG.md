# Pixiv 插件更改记录

## 2026-10-08

- 修复 PID / Pixiv 链接直取绕过分级的问题：现在会先读取作品元数据，R18/R18G 必须命中当前会话允许名单；无法确认分级时拒绝发送。
- 针对大陆服务器补充 PID 路径说明：内置 Lolicon 接口不支持按 PID 查询，无法访问 Pixiv 元数据时改为明确拒绝并提示使用关键词或 HTTP 代理。
- 恢复无代理环境下的 PID/链接直取兼容路径；未知分级仅在会话同时允许 R18 与 R18G 时发送，普通全年龄会话继续拦截。
- 加强分级字段解析：支持标签对象、`r18` 布尔字段及常见标签格式；缺失分级元数据的搜索结果会被丢弃，不再默认当作全年龄。
- `pixiv_image` 工具总超时从 60 秒提高到 120 秒。
- 多图作品默认续页上限从 4 页提高到 20 页，续页时间预算为 100 秒，合并转发图片预算为 8MB。
- 宿主合并转发上限调整为 21 条（1 条说明文字 + 20 张图片），图片合计上限调整为 16MB。
- 补充白名单查看说明：会话覆盖文件位于 `<数据目录>/plugin-state/pixiv-illust/chat-ratings.json`，也可在会话中调用 `pixiv_set_rating` 查询。

### 部署注意

Pixiv 插件位于独立的 `my-plugins` 仓库。提交并推送该仓库后，在云服务器执行该仓库的 `sync-plugins.sh`；宿主项目的 `data/` 和插件状态目录不上传 GitHub。
